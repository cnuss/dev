# Egress policy. Governs both what can be connected to and what can be
# resolved — the proxy is the sandbox's only route and its only resolver.
#
#   *               any host (open egress)
#   example.com     exact host only
#   .example.com    the domain and every subdomain
#   *.example.com   same as .example.com
#
# Edited live: the proxy re-reads this file on mtime change, no restart needed.
# Check what is loaded, and why something was denied:
#   curl -s --noproxy '*' http://proxy:8081/status | jq

# Open by default, because that is what the hosted environment does. Probing
# it with CONNECT returns 200 for every resolvable host — including
# pastebin.com, webhook.site, transfer.sh and ngrok.com. The interception and
# logging are real there; the filtering is not.
#
# Everything below this line is inert while `*` is present. Delete the `*` to
# switch to deny-by-default, and the curated list becomes the policy.
